## 📖 Description

ESCAPE.EXE is a text-based escape game where you wake up in an abandoned research facility and must find your way out by solving puzzles and exploring rooms.

Honestly, this project has been living in my head for years. Back in middle school, during technology class, I had sketched out the idea of a text-based escape game — nothing fancy, just a concept I thought was cool and never got to build properly. CS50x gave me the structure, the knowledge, and the push to finally make it real. So here it is.

Every room description is uniquely generated by AI (Groq / LLaMA), making each playthrough feel different. Your escape time is recorded on a global leaderboard shared with players worldwide.

## 🎯 How to Play

Type commands into the terminal to interact with the game:

start          — begin your escape
look           — examine your surroundings
go [direction] — move (north, south, east, west)
take [item]    — pick up an item
use [item]     — use an item from your inventory
examine [item] — examine an item closely
hint           — get a hint for the current puzzle
inventory      — check your inventory
help           — show all commands
